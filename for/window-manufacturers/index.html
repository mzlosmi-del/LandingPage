and hard to quote on a website.

Windows FAQ

Questions window manufacturers ask first.

Does the configurator show energy ratings like Uw values?

Yes. Uw, Ug, and g-value can each be a derived field on the configuration. The formula engine looks up the right value for the chosen glazing and frame combination, then displays it next to the price. The same numbers flow into the inquiry and the PDF quote so your sales and production teams see consistent specs.

Can it handle regional standards like CE marking or NFRC labels?

Yes. You can tag each glazing or frame option with the certifications that apply, and configure rules so customers in one region only see compliant options. The certification IDs travel with the inquiry and can be printed on the PDF quote, giving production a clean handoff.

Can we model custom mullion configurations?

Yes. Mullion count, position, and pattern are characteristics like any other — with rules that limit them based on overall dimensions. Pricing can scale per linear meter of mullion, or use a stepped table. The formula engine handles dependent constraints so you never quote an impossible configuration.

Can we include installation services pricing?

Yes. Add an "installation" characteristic with zones, surcharges, or per-unit pricing. The customer's postal code or region can drive the rate. The installation line item appears separately on the PDF quote, which makes it easy for your team to split out for invoicing.

Can dealers see their own catalog and pricing?

Yes — on Growth and Scale plans. Sub-tenants for dealers, each with their own price book, currency, and PDF template. Same products, same formulas, different multipliers. Dealers also get their own inquiry inbox.
